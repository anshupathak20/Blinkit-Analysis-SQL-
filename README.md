# Blinkit Grocery Data Analysis Using SQL

## 📌 Project Overview
This project focuses on analyzing Blinkit's grocery sales data using SQL to generate meaningful business insights. The analysis explores sales performance, item fat content, product categories, outlet sizes, outlet locations, and establishment years to understand sales trends and business performance.

## 🎯 Project Objectives
- Clean and standardize data for accurate analysis.
- Calculate key performance indicators (KPIs), including total sales, average sales, number of items, and average ratings.
- Identify top-performing product categories based on sales.
- Compare sales of Low Fat and Regular products.
- Analyze sales performance by outlet size, location type, and establishment year.
- Calculate the percentage contribution of different outlet sizes to total sales.

## 🛠️ Skills & Tools Used
- **SQL:** Data querying and business analysis
- **Data Cleaning:** Standardizing inconsistent fat-content values
- **Aggregate Functions:** SUM(), AVG(), and COUNT()
- **Conditional Logic:** CASE WHEN
- **Data Grouping & Sorting:** GROUP BY and ORDER BY
- **Window Functions:** Calculating sales percentage contributions
- **Data Type Conversion:** CAST() and decimal formatting
- **Business Intelligence:** KPI calculation and sales performance analysis

## 📊 Key Analysis Performed
1. **KPI Analysis:** Calculated total sales, average sales, item count, and average ratings.
2. **Fat Content Analysis:** Compared sales and other metrics for Low Fat and Regular products.
3. **Top 5 Item Categories:** Identified the five highest-selling item types.
4. **Outlet Fat Content Analysis:** Compared Low Fat and Regular product sales across outlet location types.
5. **Outlet Establishment Analysis:** Evaluated sales, average sales, ratings, and item counts by establishment year.
6. **Outlet Size Analysis:** Calculated total sales and percentage contribution by outlet size.
7. **Outlet Location Analysis:** Compared sales, average sales, item counts, and ratings across outlet location types.

## 💡 Business Value
This project demonstrates how SQL can transform raw grocery sales data into actionable business insights. The analysis helps identify high-performing product categories, compare product preferences, evaluate outlet performance, and understand the contribution of different outlet characteristics to overall sales.

## 🚀 Conclusion
The project showcases practical SQL skills through an end-to-end grocery sales analysis workflow, from data cleaning and KPI development to business-focused reporting. It demonstrates the use of SQL to support data-driven decision-making in retail analytics.
